NexLM / Apps / Harness

Harness

NexLM Harness 1.1.2. Intelligence, made closer. The local workspace for loading, prompting, and iterating on NexLM models on your own hardware.

01 / Local interface

Your models.
Your session.

Harness sits next to the model. It is built for private, on-device work: install locally, launch a web session, and keep prompts on the machine in front of you.

  1. 01Clone NexLM-Harness and install with pnpm.
  2. 02Build, then launch the local web session.
  3. 03Run NexLM models without a cloud round trip.
nexlm — harness 1.1.2
$ cd NexLM-Harness
$ git checkout master
$ git pull origin master
$ pnpm install
$ pnpm run build
$ pnpm dsh web
