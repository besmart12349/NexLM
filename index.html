01 / Local interface

Your models.
Your session.

Harness sits next to the model. It is built for private, on-device work: install locally, launch a web session, and keep prompts on the machine in front of you.

  1. 01Clone NexLM-Harness and install with pnpm.
  2. 02Build, then launch the local web session.
  3. 03Run OLLAMA models without a cloud round trip. NexLM models to add support soon.
nexlm — harness 1.2.0
Run from source
$ git clone https://github.com/besmart12349/NexLM-Harness.git
$ cd NexLM-Harness
$ pnpm install
$ pnpm run build
$ pnpm dsh web
Updating
$ cd ~/NexLM-Harness
$ git pull origin master
$ pnpm install
$ pnpm run build
$ pnpm dsh web
01 / Reasoning

Rich errors
& thinking.

Every turn surfaces the model's think steps and tool calls inline — including invalid-argument errors — so you can see exactly why a step failed and how the agent corrected course. Also supports configurable thinking modes- OFF, Low, Medium, High, Extra, XHigh, Max, Ultra- with supported LM's.

02 / Tool use

Native tool
calling.

Supported models get native tool calling instead of prompt-based function emulation. Currently supported for Ollama, with more runtimes planned.

03 / Permissions

File & workspace
permissions.

Choose Read Only, Workspace Write, or Full access per session, so the agent's file and shell access matches exactly what a task needs.

04 / Modes

Agent
modes.

Standard mode for full coding-agent capability, PTC mode for Code Mode SDK tool access, Minimal mode for a lean two-tool agent, and Creator mode for building custom agent presets.

NexLM / Research / Mission

Why we build this way.

NexLM exists to keep the balance of power in AI on the side of the person holding the device. We build models, runtimes, and tools that make real capability possible without a permanent link to someone else's server — because privacy, response time, and ownership of your own workflow shouldn't be premium features reserved for whoever can afford the biggest cluster.
